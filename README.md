# Сайт агентства «Фальков»

SEO-агентство, Санкт-Петербург. Домен: falkov-marketing.ru.

Статический сайт на SvelteKit 3 и Svelte 5 (руны), `adapter-static`, все адреса заканчиваются на `/`.

## Страницы

| Адрес | Что это |
| --- | --- |
| `/` | Главная |
| `/seo-audit/` | Бесплатный SEO-аудит |
| `/uslugi/` | Услуги: шесть направлений |
| `/keysy/` | Кейсы со ссылками на посты в Telegram и Максе |
| `/spb/`, `/msk/` | Главная под Санкт-Петербург и Москву. Ссылки на них есть только в футере |

## Где что лежит

- `src/routes/` – страницы. Шапка, футер и общая форма заявки – в `+layout.svelte`.
- `src/lib/components/agency/` – блоки: главная (`AgencyHome`), видео, плашка каналов, форма, всплывающее окно.
- `src/lib/agency.ts` – данные: услуги, кейсы, контакты, адреса офисов.
- `static/img/agency/` – логотипы клиентов, скриншоты кейсов, фото офисов. `static/video/` – видео руководителя.

## Команды

```sh
npm ci
npm run dev      # разработка
npm run check    # проверка типов
npm run build    # сборка в build/
```

Выкладка на сервер описана в `docs/deploy.md`.
